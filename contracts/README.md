Foundry project for the DBForge Solidity contracts (mission escrow, submission
acceptance, and MON reward payouts) targeting Monad Testnet.

This directory is not yet an initialized Foundry project. To set it up:

```
cd contracts
forge init --no-git --force .
```

- `src/` — contract source files
- `script/` — deployment scripts
- `test/` — Foundry tests

No contracts have been written yet — this is scaffold only.
