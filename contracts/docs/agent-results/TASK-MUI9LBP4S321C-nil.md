## 4. Decisions where ARCHITECTURE.md is silent (no interface change; please fold into the doc)
1. **Constructors:** `MissionVault(address admin)`, `MissionFactory(IMissionVault vault)`,
   `ProvenanceRegistry(address admin, IMissionVault vault)`; zero addresses → `ZeroAddress`.
2. `VERIFIER_ROLE = keccak256("VERIFIER_ROLE")` as a public constant on Vault and Registry.
3. `anchorDataset` with `sampleCount == 0` → `SampleCountMismatch(acceptedCount, 0)` (no dedicated error in §7).
   `metadataHash` is not checked for zero (not in the §5 check list).
4. `cancelMission` checks buyer first, then status → an unknown id reverts `NotBuyer`, not `MissionNotActive`.
5. `reward × target` overflow reverts with Panic 0x11 (checked math), not a custom error.
6. `setFactory` emits no event (none in §6); lint warning suppressed with a comment.
7. Events are emitted before the MON transfer (strict CEI); a failed transfer reverts them too.
8. Payout uses an assembly `call` that forwards all gas but never copies returndata (see evidence).
   Behaviour is unchanged (`TransferFailed` on failure); only the return-bomb cost is removed.
9. Storage `ReentrancyGuard` (not the transient one), so a `paris` fallback would still compile.
